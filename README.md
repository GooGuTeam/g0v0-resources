## About this fork

This repository is a fork of [ppy/osu-resources](https://github.com/ppy/osu-resources) (upstream resources), rebranded as **g0v0!resources** for the [g0v0!](https://github.com/GooGuTeam/g0v0) project. Display names have been changed to g0v0!, while the namespace and assembly (`osu.Game.Resources`) are retained for compatibility with the upstream client. The g0v0! fork publishes its rebranded resources as the NuGet package `g0v0.osu.Game.Resources`.

The upstream name is a protected trademark of ppy Pty Ltd. Any remaining references to it in this repository (e.g. the stable client, supporter, direct, the official store and wiki, game modes and the `.osu` file format) refer to the original upstream game and its services and are used nominatively. This project is not affiliated with or endorsed by ppy Pty Ltd.

## Releases

`g0v0.osu.Game.Resources` is packed and published to NuGet.org from GitHub Actions using NuGet trusted publishing. Releases are driven by tags in the form `v<version>-g0v0` (for example `v2026.913.0-g0v0`); the workflow computes the three-part NuGet version from the tag.

## Requirements

This is a dependency of [g0v0!](https://github.com/GooGuTeam/g0v0).
