## About this fork

This repository maintains resources derived from upstream for the g0v0! client. Some display names and
brand assets have been replaced; other upstream resources remain under their original licences.
The namespace and assembly (`osu.Game.Resources`) are retained for compatibility with the upstream client.
The fork publishes its resources as the NuGet package `g0v0.osu.Game.Resources`.

## Requirements

This is a dependency of [g0v0!](https://github.com/GooGuTeam/g0v0).
