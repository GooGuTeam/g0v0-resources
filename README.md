# g0v0!resources

Assets used by g0v0!.

## About this fork

This repository is a fork of [ppy/osu-resources](https://github.com/ppy/osu-resources) (osu!resources), rebranded as **g0v0!resources** for the [g0v0!](https://github.com/GooGuTeam/g0v0) project. Display names have been changed to g0v0!, while the namespace, assembly and NuGet package identity (`osu.Game.Resources`, `ppy.osu.Game.Resources`) are retained for compatibility with the upstream client.

"osu!" is a protected trademark of ppy Pty Ltd. Any remaining references to it in this repository (e.g. `osu!stable`, `osu!supporter`, `osu!direct`, `osu!store`, `osu! wiki`, game modes and the `.osu` file format) refer to the original osu! game and its services and are used nominatively. This project is not affiliated with or endorsed by ppy Pty Ltd.

## Requirements

This is a dependency of [g0v0!](https://github.com/GooGuTeam/g0v0).
